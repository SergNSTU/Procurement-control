# Текущее состояние приложения

## Общая информация

- **Тип приложения:** десктопное Windows-приложение.
- **Интерфейс:** Windows Forms (WinForms).
- **Основной язык и среда:** PowerShell 5.1.
- **ОС:** Windows 10 и Windows 11.
- **Архитектура:** portable-приложение, запускается через `Start.bat` или `Start.vbs`.
- **Веб-версии и WPF нет.**
- Основные данные хранятся локально в папке приложения.

## Технологический стек

| Область | Технология |
|---|---|
| Интерфейс | Windows Forms |
| Язык | Windows PowerShell 5.1 |
| База данных | SQLite |
| Драйвер БД | `System.Data.SQLite.dll` |
| Работа с Excel | Microsoft Excel COM Automation |
| Работа с Word-документами | Microsoft Word COM Automation |
| Файловое хранилище | Локальные папки проекта и папки сделок |
| Импорт `.xls/.xlsx` | Excel COM |
| Конфигурация | Локальная SQLite-база и настройки приложения |

## Основные разделы интерфейса

### Контроль закупки

Реализовано:

- список сделок;
- поиск по сделкам;
- горизонтальная и вертикальная прокрутка;
- создание, редактирование и удаление сделок;
- копирование номера сделки правой кнопкой мыши;
- открытие файлов в Проводнике через контекстное меню;
- фильтры: Активные, Все, Готово, Пауза, Китай, На отслеживании, Архив;
- этапы сделки: RFQ, RRFQ, PI, PO, Закупка, Заказано, ERP, Выполнено и другие рабочие этапы;
- исполнитель сделки, включая Евгения;
- место сборки: Китай или РФ;
- приоритет с возможностью оставить поле пустым;
- количество плат, клиент, комментарий и период;
- плановая и фактическая дата поступления;
- отображение готовности по поставщикам;
- цветовая подсветка сделок:
  - зелёный — все необходимые условия выполнены;
  - красный — сделка ещё требует действий;
- отдельная логика фильтрации китайских сделок и сделок, назначенных Евгению.

### Поставщики

Для каждого поставщика доступны:

- суммы PI в USD, CNY и RUB;
- ручная сумма оплаты;
- срок;
- подано в оплату;
- оплачено;
- инвойс;
- подтверждённый инвойс;
- ERP;
- ERP поставщика;
- ERP Roger;
- дата подтверждения;
- дата поступления;
- комментарий;
- расчёт готовности сделки.

Поддерживается несколько заказов одного поставщика:

```text
BEN
BEN_1
BEN_2
BEN_3
```

Для отдельных поставщиков применяются специальные правила расчёта сроков и обязательных полей.

### Документы

Реализована загрузка документов в папки проекта и папки сделок.

Типы документов включают:

- RFQ;
- RRFQ;
- Общий PI;
- PO;
- ERP;
- Other;
- документы поставщика;
- документы сделки.

Особенности:

- документы сохраняются локально;
- путь к файлу хранится в базе;
- переименование файла через Проводник не должно удалять его из списка;
- документы могут быть открыты через контекстное меню;
- документы без привязки к поставщику поддерживаются для RFQ, RRFQ, Общего PI, PO и Other.

## Задачи

Раздел «Компоненты» переименован в «Задачи».

Реализовано:

- сделки и связанные с ними задачи;
- поиск по сделкам;
- статусы задач;
- этапы, включая пустой этап, «Выполнено» и «На отслеживании»;
- синяя подсветка строк для статуса «На отслеживании»;
- ярко-красная подсветка напоминаний, если дата наступила или просрочена;
- заметки по каждой сделке;
- отдельное поле заметок для выбранной сделки;
- сохранение и редактирование заметок;
- горизонтальная и вертикальная прокрутка.

## Напоминания

Реализовано:

- напоминания по сделкам, поставщикам и компонентам;
- статусы внимания:
  - Attention — скоро поступление;
  - Danger — поступление просрочено;
- возможность отметить поступление как выполненное;
- ввод фактической даты поступления;
- хранение плановой даты отдельно от фактической даты;
- отображение новой фактической даты в контроле закупки.

## Сравнение RRFQ

Реализовано:

- загрузка RFQ;
- загрузка нескольких файлов поставщиков;
- сопоставление позиций;
- сравнение цен и сроков;
- автоматический выбор победителя;
- ручное назначение победителя;
- ручное добавление квоты;
- предупреждения при проблемах сопоставления;
- создание результирующего RRFQ;
- выгрузка результатов в Excel;
- добавление квот в базу квот;
- защита от повторного добавления одинаковых квот.

## Парсер Компэл

Реализовано:

- загрузка HTML-выгрузки Компэл;
- разбор позиций;
- обработка PN и Value;
- расчёт цены;
- расчёт Lead Time;
- специальные правила для российского поставщика Компэл;
- если Value полностью совпадает с PN, поле PN не дублируется;
- формирование Excel-файла в формате обычной выгрузки;
- кнопка «Выгрузить в сравнение»;
- автоматическое сохранение Excel в папку «Загрузки»;
- автоматическое добавление созданного файла в список поставщиков раздела «Сравнение RRFQ».

## База квот

В базе квот реализованы две вкладки.

### Наши квоты

Содержит квоты, полученные из внутренних сборок и сравнений RRFQ.

### Globalist

Содержит квоты из файлов Globalist: Mouser, DigiKey и других поставщиков.

Реализовано:

- загрузка `.xls` и `.xlsx`;
- обработка всех листов Excel-файла;
- автоматический разбор строк приложением;
- сохранение данных в таблицу `globalist_quotes`;
- повторная загрузка обновлённого Globalist-файла;
- поиск по PN, бренду, источнику и PI;
- отображение цены, суммы, MOQ, количества, остатков, сроков и других полей.

## Сравнение Excel

Есть отдельный раздел «Сравнение Excel».

Функциональность:

- загрузка двух Excel-файлов;
- сравнение ячеек друг с другом;
- выделение несовпадающих ячеек ярко-красным цветом;
- совпадающие ячейки остаются без изменений;
- сохранение результата в Excel.

## Заметки

Раздел «Заметки» поддерживает:

- создание новых текстовых заметок;
- выбор заметки из списка внутри приложения;
- переключение между заметками без Проводника;
- редактирование и сохранение заметок;
- хранение заметок в папке проекта.

## База данных

Основные таблицы SQLite:

- `deals` — сделки;
- `deal_suppliers` — поставщики сделок;
- `documents` — документы;
- `reminders` — напоминания;
- `quote_batches` — загрузки квот;
- `quote_history` — история внутренних квот;
- `globalist_quotes` — квоты Globalist;
- `settings` — настройки приложения;
- `activity_log` — журнал действий;
- таблицы задач и заметок.

## Интеграции

### Реализовано

- Microsoft Excel через COM Automation;
- Microsoft Word через COM Automation;
- локальная файловая система Windows;
- локальная SQLite-база.

### Не реализовано

В текущей версии нет прямой интеграции с Outlook, Outlook Calendar, WeChat, электронной почтой, облачными базами данных или внешними API поставщиков.

Обмен с внешними системами выполняется через импорт и экспорт файлов Excel, HTML и документов.
