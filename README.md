# Procurement Control

## Запуск на другом компьютере

1. На странице проекта нажмите **Code** → **Download ZIP**.
2. Полностью распакуйте ZIP-архив, например в `Документы`. Не запускайте файлы прямо из архива и не копируйте папку в `Program Files`.
3. Откройте распакованную папку и запустите **Start.bat**. Этот вариант оставляет окно с диагностикой, если приложению что-то мешает запуститься.
4. Для обычного тихого запуска используйте **Start.vbs**.

### Что должно быть установлено

- Windows 10 или 11;
- Windows PowerShell 5.1 (входит в Windows 10 и 11);
- .NET Framework 4.6 или новее (в Windows 10 и 11 обычно уже установлен);
- Microsoft Visual C++ Redistributable 2015–2022 (x64 и x86) — может понадобиться Windows для встроенного SQLite;
- Microsoft Excel — нужен для импорта и создания Excel-файлов;
- Microsoft Word — необязателен, используется только для части функций чтения PDF.

SQLite уже входит в состав приложения — отдельно устанавливать его не нужно.

### Если приложение не открылось

1. Запустите именно `Start.bat`, а не `Start.vbs`.
2. Скопируйте текст из чёрного окна или найдите новый файл в `Procurement_control_portable\data\logs\startup_error_*.txt`.
3. Пришлите этот текст или скриншот — по нему можно точно определить недостающий компонент.

Рабочие данные приложения хранятся локально в папке `Procurement_control_portable\data` и не загружаются в GitHub.
