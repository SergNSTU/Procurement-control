# Procurement Control (WPF 2.0)

**Procurement Control** — настольная программа для отдела закупок электронных
компонентов. Актуальная версия — **WPF 2.0**, исходники в папке `WPF 2.0`.
Папка `app`, а также `Start.bat` / `Start.vbs` в корне — устаревшая
PowerShell-версия, оставлена для истории и для работы не нужна.

## О программе

Разработана для внутреннего использования закупщиком: ведёт сделку от заявки
клиента до поступления компонента на склад, заменяя ручное отслеживание
в Excel, почте и Битрикс.

Рабочий процесс: заявка приходит из Битрикс → запрос цен у поставщиков (RFQ) →
сравнение ответов поставщиков (RRFQ) и выбор победителя → заказ и контроль
оплаты → контроль поступления на склад. Программа автоматизирует этот конвейер,
сама следит за сроками и напоминает, что делать дальше, плюс собирает
статистику по закупкам и поставщикам.

**Возможности:**

- **Контроль закупки** (главный раздел) — таблица сделок с этапами, поставщики
  и документы по каждой сделке, плитки-счётчики: активные сделки, задачи
  в работе, ожидаемое поступление, просроченное, напоминания.
- **Интеграции**: Битрикс (авто-импорт новых заявок как сделок, создание задач)
  и Outlook (черновики писем поставщикам, RFQ-рассылка, напоминания и задачи
  в Outlook, авто-импорт ответов RRFQ из почты и импорт приходов со склада).
- **Сравнение RRFQ** — импорт квот поставщиков из писем и файлов, сводное
  сравнение цен и сроков, выбор победителя, авто-напоминание «нет ответа
  на RFQ» через 48 рабочих часов.
- **Цены и аналоги** — проверка цен по артикулу (Компэл SDS), разбор
  HTML-расчёта SDS, поиск аналогов компонентов через LCSC.
- **Напоминания и задачи** — автоматические пункты «что сделать» по сделкам
  и поставщикам с учётом рабочих дней.
- **Аналитика** — дашборд (статистика заявок и заказов за период, суммы
  заказов по месяцам, конверсия заявок), рейтинг и объёмы закупок
  по поставщикам в USD.
- **Сервис** — база квот с импортом/экспортом, сравнение Excel-файлов, заметки,
  история действий, встроенное руководство пользователя.

**Технически:** WPF, .NET 8, Windows 10/11 x64; локальная база SQLite — все
данные остаются на компьютере. Сборка self-contained: на компьютере запуска
не требуется устанавливать .NET или что-либо ещё, достаточно 64-битной Windows
и права записи в папку программы (то есть не `Program Files`). Интеграции
опциональны и настраиваются локально. Рядом с приложением лежит браузерное
расширение «SDS Помощник» для работы с корзиной Компэл.

## Запуск на другом компьютере

### Вариант 1 — готовая переносимая сборка (рекомендуется)

На компьютере с установленным [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0):

1. Откройте консоль в папке `WPF 2.0\ProcurementControl`.
2. Выполните:
   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Package-Portable.ps1
   ```
3. Заберите готовый архив
   `WPF 2.0\ProcurementControl\release\ProcurementControl-Portable-win-x64.zip`
   и передайте его адресату любым способом.

На целевом компьютере:

1. Распакуйте ZIP целиком в обычную папку (например, `Документы`).
   Не запускайте программу прямо из архива.
2. Запустите `ProcurementControl.App.exe`.
3. Папка `data` поставляется пустой: при первом запуске приложение само создаст
   чистую базу SQLite и служебные каталоги. Чтобы перенести существующие данные,
   скопируйте старую папку `data` в корень распакованной папки (рядом с exe).

### Вариант 2 — сборка из исходников

1. На странице репозитория нажмите **Code** → **Download ZIP** (или выполните
   `git clone`) и распакуйте архив.
2. Установите [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
3. В консоли в папке `WPF 2.0\ProcurementControl` выполните:
   ```
   dotnet publish src\ProcurementControl.App\ProcurementControl.App.csproj -c Release -o publish
   ```
4. Запустите `WPF 2.0\Start-WPF.bat` — он открывает собранное приложение из
   `ProcurementControl\publish`. При желании можно запускать exe и напрямую.

## Данные и настройки

- Рабочие данные лежат локально в папке `data` в корне переносимой сборки и в
  репозиторий не входят.
- Токены интеграций (Bitrix-вебхук и т.п.) задаются в настройках приложения и
  хранятся только в локальной базе.

## Если приложение не открылось

1. Убедитесь, что папка распакована полностью и программа запускается не из
   `Program Files` и не из архива.
2. Посмотрите журнал ошибок: `data\logs\errors.log`.
3. Сборка 64-битная (win-x64) — 32-битная Windows не подойдёт.
