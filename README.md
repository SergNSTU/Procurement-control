# Procurement Control

Текущая рабочая версия проекта — переносимое десктопное приложение для контроля закупок.

## Технологии

- Windows Forms (WinForms);
- Windows PowerShell 5.1;
- SQLite;
- Microsoft Excel COM Automation для импорта и экспорта Excel;
- локальные папки проекта для документов и заметок.

## Запуск

Запускать приложение через:

```text
Start.bat
```

или:

```text
Start.vbs
```

Основной файл приложения находится в `app/RRFQComparer.ps1`.

В проекте сохранены старые вспомогательные материалы и прототипы, но веб-версия не является рабочим интерфейсом приложения.
