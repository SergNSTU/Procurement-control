# Procurement Control Quick Capture

## Установка в Chrome/Edge

1. Откройте страницу расширений: `chrome://extensions` или `edge://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
4. Запустите Procurement Control.
5. Выделите текст на странице, нажмите правой кнопкой и выберите `Procurement Control → Создать задачу` или `Создать напоминание`.

Для настольных приложений используются глобальные хоткеи: `Ctrl+Shift+T` и `Ctrl+Shift+R`.
