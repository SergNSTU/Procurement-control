# Procurement control

Portable-приложение для Windows. Запускается через `Start.vbs` без консольного окна или через `Start.bat`, использует установленный Microsoft Excel в скрытом режиме для чтения и записи `.xls/.xlsx`.

## Как пользоваться

### Desktop версия

1. Запустите `Start.vbs` для запуска без окна `cmd.exe` или `Start.bat` как запасной вариант.
2. В левом меню выберите раздел: `Сравнение RRFQ`, `Контроль закупки`, `Компоненты`, `Напоминания`, `База квот`, `История`, `Компэл Парсер`, `Поиск цен`, `Инструкции` или `Настройки`.

#### Сравнение RRFQ

1. Выберите исходный RFQ.
2. Добавьте файлы поставщиков и проверьте автоопределенный столбец `Поставщик`.
3. Выберите приоритет: `Цена` или `Срок`.
4. Нажмите `Сформировать preview`.
5. Проверьте победителей, предупреждения и несопоставленные строки. В preview показывается причина выбора победителя и подозрительные цены, если цена отличается более чем в 10 раз от других предложений.
   При необходимости используйте ручное сопоставление, ручной выбор квоты или ручной ввод квоты.
6. Нажмите `Создать результирующий RRFQ`.

Исходные файлы не меняются. Результат создается рядом с RFQ с суффиксом `_RRFQ_result.xlsx`.
После анализа все найденные квоты сохраняются в локальную `База квот`.

#### Контроль закупки

1. Создайте сделку вручную или нажмите `Импорт из RRFQ` и выберите результирующий RRFQ.
   При импорте RRFQ копируется в папку сделки `RRFQ` и появляется в документах сделки.
2. В верхней таблице отслеживайте сделку по клиенту, периоду и стадии: `RFQ`, `RRFQ`, `PO`, `PI`, `Закупка`.
3. В блоке выбранной сделки заполните клиента, период, статус и комментарий, затем нажмите `Сохранить`.
4. Добавьте поставщиков, если они не были импортированы.
5. Отмечайте статусы по каждому поставщику: получение/подтверждение инвойса, заказ поставщику, отправка ERP поставщику и Роджеру, подача в оплату и оплату.
6. Заполняйте суммы PI в `$` и `¥`, срок в неделях и дату подтверждения инвойса. Даты выбираются через календарь.
7. Дата поступления считается автоматически: дата подтверждения + срок + 2 недели + ближайший вторник. Ее можно вручную поменять через календарь.
   Если расчетная дата уже вторник, она остается без сдвига. В списке сделок показывается самая поздняя дата поступления среди поставщиков.
8. Перетащите файлы в таблицу документов, выберите тип документа, и приложение скопирует их в хранилище.
9. Для документов `PI/Invoice` приложение быстро отмечает инвойс как полученный, но не читает PDF прямо во время drag and drop.
10. Кнопка `Считать PI` читает суммы из уже загруженных PDF выбранного поставщика. Для `Ben`, `Компэл` и `Промэлектроника` авто-чтение суммы отключено, суммы заполняются вручную.
11. Открывайте загруженные документы двойным кликом. Удаление доступно правой кнопкой мыши по документу: `Удалить`.
12. Сделку можно отправить `В архив`: документы и история остаются, но сделка скрывается из активного списка. Через фильтр `Архив` или `Все включая архив` ее можно найти и вернуть.

Приложение автоматически подсвечивает, что требует внимания: нет PI, PI не подан в оплату, не оплачено, нет даты подтверждения, не отправлен ERP, поступление просрочено или нет следующего действия.

При удалении сделки удаляются записи, документы и папка этой сделки в хранилище документов.

Данные закупки хранятся в SQLite базе `data\purchase_control\purchase_control.sqlite`. Документы по умолчанию копируются в `data\purchase_control\files`. Путь к папке документов меняется в разделе `Настройки`.
В этой же SQLite базе хранятся `Компоненты`, `История`, `Напоминания`, `Шаблоны этапов` и `База квот`.

#### Компоненты

Раздел для оперативного отслеживания компонентных сделок. Строки добавляются кнопкой `Новая сделка`, даты напоминания и дедлайна выбираются через календарь, статус/этап/приоритет/период выбираются из списков. Таблица поддерживает горизонтальную прокрутку, изменение ширины колонок и сортировку по `Статус` и `Приоритет`.

#### Напоминания, история и база квот

- `Напоминания` показывает просроченные, сегодняшние и ближайшие задачи внутри приложения.
- `История` фиксирует создание и изменение сделок, поставщиков, документов, компонентов, импорт RRFQ и изменение статусов.
- `История` можно очистить кнопкой `Очистить историю`, что удобно во время тестов на примерах.
- `База квот` хранит историю квотирования по `Value`, `PN`, поставщику, производителю, цене, сроку и признаку победителя. Найденные строки можно экспортировать в Excel, выбранные строки можно удалить, а тестовую базу можно полностью очистить.


## Перенос на другой компьютер

На GitHub проще всего нажать `Code` → `Download ZIP`, полностью распаковать архив в `Документы` и запустить верхний `Start.bat`. Не запускайте файлы прямо из ZIP и не размещайте приложение в `Program Files`: приложению нужен доступ на запись к папке `data`.

Для desktop-версии нужны Windows 10/11, Windows PowerShell 5.1 и .NET Framework 4.6 или новее. Для встроенного SQLite в некоторых конфигурациях Windows также нужен Microsoft Visual C++ Redistributable 2015–2022 (x64 и x86). Для чтения и записи Excel-файлов требуется установленный Microsoft Excel. Если запуск не удался, откройте `data\logs\startup_error_*.txt` и передайте файл вместе со скриншотом ошибки.

Можно также копировать всю папку приложения на другой Windows-компьютер. Для desktop-версии нужен установленный Microsoft Excel и разрешение запуска PowerShell-скриптов через приложенные `.bat` файлы.
Для переноса важна вся папка целиком: `app`, `config`, `data`, `Start.bat` и `Start.vbs`. Если документы хранятся во внешней папке, ее тоже нужно перенести или заранее вернуть путь документов внутрь папки приложения через `Настройки`.

SQLite-компонент для контроля закупки лежит в `app\lib\sqlite`, отдельно устанавливать SQLite не нужно.

Авто-чтение сумм из PDF использует установленный Microsoft Word, если он доступен. Если PDF сканированный или Word не установлен, сумму можно заполнить вручную в таблице поставщиков.

История действий, напоминания, шаблоны этапов и база квот находятся в той же portable SQLite-базе `data\purchase_control\purchase_control.sqlite`.

## Примечания

- Скрытые строки поставщиков игнорируются.
- Для Компэла цена сравнения считается как `Цена за шт / 1.22`, а в результирующем файле добавляется колонка `Unit price (с НДС)`.
- Для Ben `Lead time (total)` равен исходному `Lead Time`.
- Валюты кроме USD попадают в предупреждения и не участвуют в выборе победителя.
